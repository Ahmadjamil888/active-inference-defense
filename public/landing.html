Installation

Install AISS from GitHub. Works on Windows, macOS, and Linux.

Clone the repository
git clone https://github.com/Ahmadjamil888/active-inference-defense.git
Install the CLI globally
cd active-inference-defense/agent && npm install -g .
Start AISS
aiss
